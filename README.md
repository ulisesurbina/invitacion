# Invitación React — azul y plateada

Edita contenido en `src/config.js` y diseño en `src/styles.css`.

## Google Maps
En `src/config.js` cambia `locationUrl` por el enlace exacto de Google Maps. La ubicación es clickeable y abre Maps en otra pestaña.

## Boleto
La invitación incluye: **ENTRADA SOLO CON BOLETO**. El texto se puede modificar en `src/main.jsx`.

## Google Sheets
Usa `google-apps-script/Code.gs`. En Google Sheets: Extensiones > Apps Script > pega el código > Implementar > Nueva implementación > Aplicación web > ejecutar como tú > acceso cualquiera. Copia la URL `/exec` a `DESIGN.googleSheetsUrl`.

## Netlify
`npm install` → `npm run build`; en Netlify usa build command `npm run build` y publish directory `dist`.
